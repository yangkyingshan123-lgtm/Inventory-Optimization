# Supply Chain & Drone Intelligence Digital Twins

This repository contains a collection of Python-based simulations and dashboards developed in 2026.

## Included Projects

### 1. Inventory Optimization Digital Twin
A real-time simulation for supply chain monitoring, featuring dynamic safety stock calculations and emissions tracking.

### 2. Drone Performance Intelligence
A Streamlit-based dashboard for analyzing global drone fleet data and weather-based flight safety checks.

### 3. Logistics Optimization Agent
Genetic algorithm-based agents for solving routing and lumpy demand challenges.
